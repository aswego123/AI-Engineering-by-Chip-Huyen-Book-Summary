- [`dspy`](https://github.com/stanfordnlp/dspy) — programmatic prompt optimization.
- [`outlines`](https://github.com/dottxt-ai/outlines) — constrained decoding.
- [`guidance`](https://github.com/guidance-ai/guidance) — templated generation.
