# 🧪 Agents — Code

## Suggested mini-projects
1. **ReAct from scratch** — no framework, 100 lines. Search + calculator + Python.
2. **Function-calling agent** — same, but using native `tools` API.
3. **LangGraph state machine** — planner → executor → critic loop.
4. **MCP server** — expose 3 tools; consume from Claude Desktop / VS Code.
5. **SWE-bench-lite try** — pick 5 issues, see how far your agent gets.

## Frameworks
- [`langgraph`](https://github.com/langchain-ai/langgraph) — graph-based, explicit state.
- [`crewai`](https://github.com/crewAIInc/crewAI) — role-based multi-agent.
- [`autogen`](https://github.com/microsoft/autogen) — Microsoft, conversational.
- [`pydantic-ai`](https://ai.pydantic.dev/) — typed, minimal.
- [`smolagents`](https://github.com/huggingface/smolagents) — Hugging Face, code-writing agents.
- [`fastmcp`](https://github.com/jlowin/fastmcp) — MCP servers in Python.
