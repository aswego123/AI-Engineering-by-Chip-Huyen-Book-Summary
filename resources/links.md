# 🔗 Learning Resources

- **AI Engineering** by Chip Huyen (~800 pages) — the "bible" of this field
- Author's site: https://huyenchip.com/

## 🎥 Videos

- [AI Engineering in 76 Minutes (Complete Course Speedrun!)](https://www.youtube.com/watch?v=JV3pL1_mn2M) — the video these notes are based on
- **StatQuest** on YouTube — great for understanding Transformers & attention

## 🛠️ Frameworks to Try

| Tool | What It Does |
|------|--------------|
| **LangChain** | Full orchestration framework for LLM apps |
| **LlamaIndex** | Best-in-class RAG framework |
| **DSPy** | Prompt optimization / automated prompt engineering |
| **Haystack** | End-to-end LLM pipelines |
| **Flowise / Langflow** | Visual (no-code) pipeline builders |

## 🏃 Suggested First Projects (Beginner Order)

1. **Prompt experimentation** — use ChatGPT playground / Claude
2. **Simple RAG** — chat with a PDF using LlamaIndex
3. **Basic agent** — LangChain agent with 2-3 tools
4. **Fine-tune with LoRA** — small model on Hugging Face
5. **Full app** — deploy a small AI app with monitoring
